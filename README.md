# ReVizMachine
A revision for VizMachine - Virtual machine and memory used for eLearning - simulates a CPU and RAM with a reduced set of opcodes

If you want to run the ReVizMachine, copy the folder revizmachine to your local folder and run index.html. Mind to use either Firefox or Chrome. Internet Explorer won't work for ReVizMachine.

Demo at
https://omerfaruknehir.github.io/revizmachine/
